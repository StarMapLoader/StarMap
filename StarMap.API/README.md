# StarMap API

`StarMap.API` is the public API package for mods loaded by StarMap. It targets .NET 10.

For the current, versioned modding guide—including project setup, lifecycle callbacks, services, and dependencies—see the [StarMap documentation](https://starmaploader.github.io/StarMap/latest/modding/).

The package version is not guaranteed to match the StarMap application version. Use a `StarMap.API` version compatible with the loader you intend to support.

Additional examples are available in the [StarMap-ExampleMods repository](https://github.com/StarMapLoader/StarMap-ExampleMods).
