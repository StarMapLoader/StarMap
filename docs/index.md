# StarMap

StarMap is a .NET mod loader for Kitten Space Agency (KSA). It loads mods listed by KSA and gives mod assemblies lifecycle hooks and services through the `StarMap.API` package. Each mod is loaded in its own .NET assembly load context to help isolate its dependencies.

StarMap is an actively developed prototype. Check that a mod targets a compatible StarMap/API release and KSA version.
